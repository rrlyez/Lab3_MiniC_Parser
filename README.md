# Lab 3 — MiniC Parser

MiniC Parser — навчальний синтаксичний аналізатор підмножини мови C, розроблений з використанням Flex та Bison.

Програма виконує лексичний і синтаксичний аналіз, будує абстрактне синтаксичне дерево (AST), інтерпретує програму та генерує Python-код.

## Можливості

- Оголошення цілочисельних змінних (`int`).
- Присвоєння значень.
- Арифметичні та логічні операції.
- Умовні конструкції `if/else`.
- Цикли `while`.
- Вкладені блоки коду.
- Виведення результатів через `print()`.
- Побудова та виведення AST.
- Генерація Python-коду.
- Візуалізація AST через Graphviz і D3.js.
- Обробка синтаксичних помилок та окремих помилок виконання.

Підтримується навчальна підмножина C, а не повний стандарт мови. `print()` є додатковою навчальною конструкцією.

## Використані технології

C++20, Flex, GNU Bison, GNU Make, Graphviz, HTML, CSS, JavaScript, D3.js.

## Компіляція

Команди виконуються в терміналі MSYS2 UCRT64 із головної папки проєкту.

```bash
make
```

Для повної повторної збірки:

```bash
make clean
make
```

## Запуск

```bash
./output/minic.exe < tests/interpreter_test.c
```

Для запуску стандартного тесту:

```bash
make test
```

## Генерація Python-коду

Після успішного виконання програми створюється файл `output/generated.py`.

Його можна запустити командою:

```bash
python output/generated.py
```

## Візуалізація AST

Для створення SVG-дерева:

```bash
make visualize
```

Результат зберігається у файлі `output/ast.svg`.

Для інтерактивного перегляду AST:

```bash
python -m http.server 8000 --directory web
```

Відкрити в браузері:

http://localhost:8000

Вебінтерфейс підтримує масштабування, переміщення дерева та згортання гілок.

## Структура проєкту

- `src/` - вихідний код аналізатора та інших модулів.
- `include/` - заголовкові файли C++.
- `tests/` - тестові програми.
- `web/` - вебвізуалізація AST.
- `output/` - згенеровані файли.
- `Makefile` - автоматизація компіляції.

## Тестування

У папці `tests` є приклади для перевірки арифметики, умов, циклів, областей видимості та обробки помилок.

Некоректний синтаксис можна перевірити командою:

```bash
./output/minic.exe < tests/invalid_syntax.c
```

Програма має повідомити про синтаксичну помилку.
